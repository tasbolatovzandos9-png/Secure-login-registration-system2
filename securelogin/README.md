# Secure Login System

## Project Description
This project is a secure user registration and login system developed using Java and Spring Boot.

The application provides user authentication, password encryption, and role-based access control.

## Technologies Used
- Java 21
- Spring Boot 4.1.2
- Spring Security
- Spring Data JPA
- Maven
- H2 Database
- Thymeleaf
- BCrypt Password Encoder

## Features
- User Registration
- User Login and Logout
- Password Encryption using BCrypt
- User Authentication
- Role-Based Access Control (RBAC)
- 12 User Roles
- Admin Panel
- Manager Dashboard
- H2 Database Integration

## User Roles
1. SUPER_ADMIN
2. ADMIN
3. MANAGER
4. SENIOR_REVIEWER
5. MODERATOR
6. SUPPORT
7. ANALYST
8. REVIEWER
9. USER
10. PREMIUM_USER
11. VERIFIED_USER
12. AUTHOR

## Installation and Running

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project in Visual Studio Code.

3. Run the application:
   ```bash
   .\mvnw.cmd spring-boot:run
   ```

4. Open in your browser:
   ```text
   http://localhost:8080
   ```

## Database
The project uses the H2 database with Spring Data JPA.
