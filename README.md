# 🔐 Қауіпсіз тіркелу және авторизация жүйесі (Secure Login System)

**Java және Spring Boot** технологиялары негізінде жасалған қауіпсіз пайдаланушыны тіркеу және жүйеге кіру веб-қосымшасы.

## 📌 Жоба туралы

Secure Login System — пайдаланушыларды тіркеуге, жүйеге кіруге, құпиясөздерді қауіпсіз сақтауға және пайдаланушылардың рөлдеріне қарай қолжетімділікті басқаруға арналған веб-жүйе.

Жобада Spring Security көмегімен аутентификация және авторизация механизмдері жүзеге асырылған.

## 🚀 Жобаның негізгі мүмкіндіктері

- Пайдаланушыны тіркеу.
- Жүйеге кіру және шығу.
- Құпиясөздерді BCrypt алгоритмімен хэштеу.
- Spring Security арқылы аутентификация.
- Рөлдерге негізделген қолжетімділікті басқару (RBAC).
- Рөлдер иерархиясы.
- Әкімшілік басқару панелі (Admin Panel).
- Пайдаланушыларды басқару.
- Пайдаланушы рөлдерін өзгерту.
- H2 дерекқорымен жұмыс.
- Thymeleaf арқылы веб-беттерді көрсету.
- CSRF қорғанысы.

## 👥 Пайдаланушы рөлдері

Жүйеде 12 түрлі рөл қарастырылған:

1. `ROLE_SUPER_ADMIN` — бас әкімші.
2. `ROLE_ADMIN` — әкімші.
3. `ROLE_MANAGER` — менеджер.
4. `ROLE_SENIOR_REVIEWER` — аға тексеруші.
5. `ROLE_MODERATOR` — модератор.
6. `ROLE_SUPPORT` — техникалық қолдау маманы.
7. `ROLE_ANALYST` — сарапшы.
8. `ROLE_REVIEWER` — тексеруші.
9. `ROLE_USER` — қарапайым пайдаланушы.
10. `ROLE_PREMIUM_USER` — премиум пайдаланушы.
11. `ROLE_VERIFIED_USER` — расталған пайдаланушы.
12. `ROLE_AUTHOR` — автор.

## 🛠️ Қолданылған технологиялар

| Технология | Мақсаты |
|---|---|
| Java 21 | Бағдарламалау тілі |
| Spring Boot 4.1.2 | Backend әзірлеу |
| Spring Security | Қауіпсіздік және авторизация |
| Spring Data JPA | Дерекқормен жұмыс |
| Hibernate | Объектілік-реляциялық байланыс |
| H2 Database | Дерекқор |
| Thymeleaf | Веб-интерфейс |
| Maven | Жобаны құрастыру |
| BCrypt | Құпиясөздерді хэштеу |

## ⚙️ Жобаны орнату және іске қосу

### 1. Репозиторийді жүктеу

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Жоба бумасына кіру

```bash
cd securelogin
```

### 3. Бағдарламаны іске қосу

Windows PowerShell терминалында:

```powershell
.\mvnw.cmd spring-boot:run
```

### 4. Браузер арқылы ашу

```text
http://localhost:8080
```

## 🔑 Жүйенің негізгі беттері

| Бет атауы | URL мекенжайы |
|---|---|
| Тіркелу | `/register` |
| Жүйеге кіру | `/login` |
| Басты бет | `/home` |
| Әкімшілік панель | `/admin` |
| Менеджер панелі | `/manager` |

## 🔒 Қауіпсіздік мүмкіндіктері

- Құпиясөздер ашық түрде сақталмайды.
- BCrypt арқылы құпиясөздер хэштеледі.
- Spring Security арқылы қорғалған беттерге рұқсат беріледі.
- Әр пайдаланушының қолжетімділігі оның рөліне байланысты анықталады.
- CSRF қорғанысы қолданылады.
- Рұқсаты жоқ пайдаланушылар қорғалған бөлімдерге кіре алмайды.

## 🎯 Жобаның мақсаты

Жобаның негізгі мақсаты — пайдаланушыларды тіркеу және авторизациялау жүйесін құру, ақпараттық қауіпсіздікті қамтамасыз ету және рөлдер арқылы қолжетімділікті басқару механизмдерін тәжірибе жүзінде жүзеге асыру.
